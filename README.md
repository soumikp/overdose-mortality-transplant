# 2025_srtr

Code and data repository for 'Drug Overdose Mortality Decline and Deceased Donor Transplantation in the United States' by Sethi et al. (2026). We have organized this repository so that each folder in \code\submission2 contains data and code that will generate the associated figure. Please install the package below to ensure the code can run without issues.

```{r}
install.packages("pacman")
```
